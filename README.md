# 🚲 Bike Sharing Demand Analysis

## 📌 Overview
This project analyzes a bike-sharing dataset to understand the factors influencing rental demand and build a predictive model using Linear Regression.

---

## 🎯 Objectives
- Perform exploratory data analysis (EDA)
- Identify key variables affecting demand
- Build a linear regression model
- Validate model assumptions

---

## 🛠️ Tools & Technologies
- Python  
- Pandas  
- NumPy  
- Matplotlib / Seaborn  
- Scikit-learn  

---

## 📊 Key Steps
- Data cleaning and preprocessing  
- Exploratory data analysis (EDA)  
- Correlation analysis  
- Model building using Linear Regression  
- Model evaluation and assumption validation  

---

## 📈 Insights
- Demand varies significantly with season and temperature  
- Weather conditions impact rental usage  
- Working days and holidays influence demand patterns
